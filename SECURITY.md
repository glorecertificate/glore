# Security policy

## Supported versions

Only the latest release gets security fixes.

## Report a vulnerability

Do not open a public issue. Use [private vulnerability reporting](https://github.com/glorecertificate/glore/security/advisories/new) on GitHub instead.

If you have no GitHub account, write to info@glorecertificate.net.

Include the affected page or file, the steps to reproduce the problem and its effect.
