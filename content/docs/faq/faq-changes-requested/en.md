---
title: 'What if my tutor asks for changes or rejects my request?'
excerpt: 'With changes requested you edit and send again. A rejected request ends, and you see the reason.'
---

If the tutor asks for changes, open the request and read their comments. Edit the sections they point to and submit it again. It goes back to the same tutor while they are still available.

If the tutor rejects the request, you see their reason. A rejected request is closed. Talk to your tutor or organization about what would need to be different, and send a new request when you are ready.

You can also withdraw a request yourself while it is still open.
