---
title: '¿Cómo comparto mi certificado?'
excerpt: 'Descarga el PDF, copia el enlace, muestra el código QR o añádelo a LinkedIn.'
---

Abre tu certificado aprobado en Certificados. El panel para compartir te ofrece:

- el PDF para descargar,
- un enlace para copiar,
- un código QR,
- un atajo para añadir el certificado a tu perfil de LinkedIn.

Cualquiera que tenga el enlace o el código puede ver el certificado y su página de verificación.
