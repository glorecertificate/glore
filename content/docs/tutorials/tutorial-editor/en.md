---
title: 'Tutorial for editors'
excerpt: 'Create and translate courses, publish them per language, and write documentation.'
---

Editors write the content learners see. You do not see the Organization or Certificates areas.

## Create a course

1. Open Courses and select New course.
2. Fill in the title, description, icon, course type, duration and outcomes. For a skill course, choose its skill group.
3. Add lessons. The editor handles headings, lists, quotes and links. Type / to open the AI assistant, which can generate, improve, summarize and translate text. Always read what it writes.
4. Add quiz questions to a lesson. Each question has several options, exactly one correct, and an explanation that teaches why.
5. In the last lesson of a skill course, add the self-assessment statements and the final assessment.

## Translate and publish

1. Write the course in each language: English, Spanish and Italian. The AI assistant can draft a translation for you to review.
2. Publish each language when it is ready. A language is published once all lessons have content, and learners only see the languages you published.
3. Use the learner preview to walk through the course as a learner would. Nothing you do there is saved.
4. Open the course analytics to see enrollments, completions and ratings.

## Edit the skill framework

Open the [skills page](/courses/skills) to edit skill groups, their descriptions and their order.

## Write documentation

1. Open Documentation and, inside a category, select New article.
2. Enter a title and a slug, pick the category, and write an excerpt and the content in each language. The content uses Markdown.
3. Turn on Published when the article is ready. Unpublished articles stay drafts that only editors can see.
